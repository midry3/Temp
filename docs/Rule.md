# コーディング規約
- `>`, `>=`を使わない
- `!`の代わりに`not`を使う(`!=`はこの限りではない)
- コンポーネント指向で設計する。`Novot`は`Scene`を継承することにより部品を作ることが可能なので、再利用可能は部分はファイルを分けて実装する
- 関数の引数定義の部分では改行しないこと
- classは`PascalCase`、private, protectedなメンバ変数は`_var`、ローカル変数は`camelCase`
- 可能な限り`const`を使う
- `std::max`, `std::min`, `std::clamp`等は使わず、代わりに`Max`, `Min`, `Clamp`を使う
- HLSLコードとラッパークラスは全て`Shader/`に書く
- Novot側のコードは許可なく変更しない
- ゲームのリリースビルドに関係ないファイル（エディタ設定や作業用キャッシュ等）は Assets/ ではなく _Tools/ ディレクトリに入れること
