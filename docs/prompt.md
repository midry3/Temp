# 将棋ライクな盤面移動の実装
盤面はm x n (可変)
各マスにはそれぞれNormal, Disabled(通行不可), その他地形ギミックの属性が付与される
敵、味方はそれぞれ各ターン1手ずつ進める
味方は
- 周囲8マス + 斜め無制限(a)
- 周囲8マス(b)
- 周囲24マス(c)
- 縦横に無制限(d)
の動きが出来る4体がいる
配置は各ステージで異なるので、指定出来るようにするが、デフォルトは盤面中央に
 ,b,
a, ,c
 ,d,
の形で並ぶ

敵は簡単のため、前に1マスだけ進むことにする


# 成果物
- この盤面を`BoardBase.h`に実装する
- 各タイルのテクチャ、初期盤面(タイルの属性や敵味方の配置)などは、外部データファイルから読み込む。Luaかjsonの好ましい方で。
